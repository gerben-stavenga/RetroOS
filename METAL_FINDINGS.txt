QEMU KVM correctness fixes, 2026-11-10 (supersedes failed TEMP/cleanup notes)
--------------------------------------------------------------------------
Reproduced and fixed distinct kernel/filesystem errors; these are not a
claim that the remaining physical-machine slowdown has been explained.

1. FAT positioned writes: rust-fatfs seek clamps positions beyond EOF. The
   adapter ignored the returned position, so assembler writes intended beyond
   its reserved header overwrote earlier data. It now zero-fills the gap before
   writing. Independent cached readers are invalidated before mutation so
   stale cached directory entries cannot restore an old file size. The native
   ext4-root / RAM-FAT-TEMP single-step GCC compile, link and execution passes.
2. kill: 64-bit syscall 62 previously returned success without checking the
   target or sending a signal; 32-bit syscall 37 was absent. Both now use the
   existing process signal machinery, check liveness and reject bad signals.
   Both ABIs pass a blocked-child SIGKILL/reap test; 64-bit caught/blocked
   signal delivery also passes. This does not add missing thread-group APIs.
3. Open-file cleanup: Codex keeps an arg0 .lock descriptor open while unlinking
   its name and removing its directory. SMB previously left a delete-pending
   name visible until close; native ext4 explicitly returned EBUSY. SMB now
   moves local open files to unique temporary names within the configured
   mount root, marks them for deletion on last close, and hides those tracked
   names from guest enumeration. Native ext4 uses the standard legacy orphan

New lib/src/heap/tree.rs is an intrusive AVL index ordered by address, with

allocations, preserves stronger requested alignments and prevents untrackable
split tails. Window edges align inward; growth clamps to the supplied end even
for a partial final page. Retained backing limits, small caches, release callback
and physical-page reclamation remain. Tests destroy released contents to verify
surviving tree headers stay mapped and live allocations stay intact.
