DOSMID TEST BUNDLE
==================

DOSMid v0.9.8 is a real-mode DOS MIDI/MUS/RMID player by Mateusz Viste.
The bundled DOSMID.EXE is the normal build; DOSMIDLT.EXE is the lower-memory
Lite build without AWE32 support.  DOSMID.TXT contains the complete manual.

Run from this directory, for example:

  DOSMID.EXE /mpu=330 WALLRAG.MID

Bundled music:

  WALLRAG.MID  Scott Joplin, "Wall Street Rag" (about 3 min 27 sec)
  BRAHMS3.MID  Brahms, Op. 118 No. 3 (about 3 min 44 sec)
