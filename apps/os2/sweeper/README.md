# OS/2 Sweeper compatibility fixture

`SWEEPER.EXE` is the original 32-bit OS/2 Presentation Manager shareware game
by Gordon Reeder. It is kept unmodified together with every file from its
distribution archive, as required by the redistribution terms in `README.DOC`.

- EXE SHA-256: `0167ea5de5871aa85a9af55b90ed1f166650ea647dded054ef36ff34b8fd088a`
- HLP SHA-256: `1e9464903fcb066eacf6b35a3129e760c2836c697530a4b8c052d39b7be7ba25`
- `README.DOC` SHA-256: `7905ed487baa74b5bdd817089e1c00fffb8dcde4f2b71ad195c18a84ac8da9ed`
- `SWEEPER.DOC` SHA-256: `9c3a891911b1784ee9d5dc26c4d8d63442a917be46f32269691c48af834c04e9`

The upstream readme explicitly encourages redistribution provided all original
files are included. This package is RetroOS's acceptance fixture for native
OS/2 LX loading and PMWIN/PMGPI window, bitmap, input, and timer behavior.
